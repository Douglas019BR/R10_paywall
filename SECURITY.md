# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository (the
**Report a vulnerability** button under the Security tab). Do not disclose the
issue in a public issue, discussion or social post until a fix is available.

Include the affected version, steps to reproduce and the potential impact. You
should receive an acknowledgement within a few days.
